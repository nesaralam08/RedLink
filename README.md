# ReadLink

**ReadLink** is a full-stack web application developed using the **MERN stack** (MongoDB, Express.js, React.js, Node.js) integrated with **Machine Learning** to facilitate seamless blood donation and requests between donors and recipients.

## 🔍 Features

- **Nearby Hospitals & Blood Availability**
  - Uses geolocation to help users find nearby hospitals and check their current blood stock.

- **Blood Request System**
  - Enables requesters to locate and connect with nearby donors based on blood group compatibility.

- **Email Notifications**
  - Donors receive instant email alerts when a requester matches their blood group and location.

- **Donor Directory**
  - Displays a list of nearby donors along with their blood group and contact information (as permitted).

- **Blood Donation Eligibility Check**
  - A Machine Learning model helps determine whether a donor is eligible to donate blood based on health parameters.

- **Hospital Registration & Verification**
  - Hospitals can register and log in. All registrations are verified by an authorized authority to ensure authenticity.

- **Upcoming Feature**
  - A chatbot powered by Machine Learning to assist users with common queries and tasks.

## 🛠️ Tech Stack

- **Frontend**: React.js, HTML, CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Authentication**: JWT, Email Verification  
- **Machine Learning**: Python-based ML model integrated via API  
- **Geolocation**: HTML5 Geolocation API  
- **Email Service**: Nodemailer

---

> ReadLink aims to bridge the gap between blood donors, recipients, and hospitals — ensuring faster, smarter, and safer blood donation processes.
